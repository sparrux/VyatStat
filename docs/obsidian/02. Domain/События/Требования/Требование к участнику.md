### Назначение

**Требование к участнику** - это условие, которому должен удовлетворять [[VyatStat/CLEAN VIEW/02. Domain/События/Участник события|Участник события]]. Требования имеют различные типы подтверждения выполнения условия:
1. Вручную - указывается пользователем (-ями), которых выбирает [[Организатор события]].
2. Автоматически - автоматически подтверждается через программный, заранее заготовленный скрипт приложения.

Требование прикрепляется к указанным [[VyatStat/02. Domain/События/Участник события|Участник события]] в рамках [[Событие]].

### Атрибуты

- ID
- Название требования
- Исполнители требования ([[Запросы на участие]]) в рамках события
- Проверяющие требования роли участников в рамках события
- ?Скрипт автоматического подтверждения
- Требование для всех участников (bool)
