### Назначение

**Цель события** - ожидаемый результат, которого необходимо достичь в ходе выполнения события. Цель может быть по итогу мероприятия выполнена или не выполнена. В выполнении цели будут задействованы конкретные исполнители.
### Атрибуты

- ID
- Название
- Статус: Выполнено / Не выполнено
- Исполнители
