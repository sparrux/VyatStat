### Назначение

**Задача цели** - это действие или совокупность действий, описывающее алгоритм достижения [[Цель события]]. Задача может как для всех участников события, так и для конкретных индивидуумов, которых указывает [[Организатор события]] на этапе написания отчета. Это позволит отследить, какой алгоритм выполняли конкретные [[VyatStat/02. Domain/События/Участник события|Участник события]].

### Атрибуты

- ID
- Название задачи
- [[Цель события]]
- Исполнители цели / Принимающие участие [[VyatStat/02. Domain/События/Участник события|Участник события]]
