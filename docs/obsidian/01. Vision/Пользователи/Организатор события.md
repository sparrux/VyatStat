**Организатор события** - это пользователь системы, который **находится в рамках организаторского состава мероприятия**. В организаторский состав может быть добавлен любой пользователь только другим организатором этого конкретного мероприятия.

> Организатор это любой пользователь, проводимый конкретное мероприятие.

**Потребности:**
- Вкусно поесть
- Сладко поспать
